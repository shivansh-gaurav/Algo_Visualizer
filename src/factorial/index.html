Factorial Visualizer (portable folder)

This folder contains the following files for the Factorial visualizer:

  • FactorialVisualizer.jsx — React component
  • factorialSteps.js — algorithm steps and helpers
  • FactorialVisualizer.css — styles used by the component
  • index.html — this file (portable entry)

To run inside the app, import the component into your React routing and ensure the CSS is included by the bundler.
